# ClueShelf MVP 規格

狀態：使用者已確認，第二階段實作與驗證中。2026-11-01。

## 目標與範圍

先完成可自用的本地網站，保留正式產品的資料與模組邊界。YouTube、Instagram、Threads 的主動收藏為測試基準，繁體中文介面，繁中與日文優先搜尋。台灣、日本、韓國餐廳、景點與演唱會地圖為主要特色。

不包含觀看紀錄、YouTube 與 Instagram 的其他使用者留言、平台登入憑證、完整影片下載、語音轉文字、截圖辨識、平台歷史收藏批次匯入、路線規劃、公開註冊與雲端部署。Threads 依後續確認，例外讀取可取得範圍的頂層熱門留言，規則見 phase-two.md。

## 使用流程

- 貼連結立即保存，背景取得公開標題、作者內文與中繼資料；不足時補內文。圖片不可取得時用平台圖示。
- 同一使用者同一平台內容依平台 ID 去重，重複加入回原收藏；不同貼文可連到同一地點。
- AI 自動套用可修改的分類與標籤，擷取有原文依據的專用欄位；缺漏留空，不憑空補熱量、地址、座標與日期。
- 主題：食譜、餐廳、旅遊、音樂、程式、語言學習、求職、活動、其他，可複選；原文保留原語言，摘要與標籤預設繁中。
- 地點查詢由使用者按鈕觸發，確認候選或手動選點後上圖。收藏與地點為多對多。
- 活動與場館分開，同一公告可對應多場活動；日期不足標待補充，不猜年份。確認場館即可上圖，完整日期才加入日期篩選。保存當地時區。
- 支援收藏卡片、詳情、地圖與列表切換；篩選平台、主題、標籤、內容語言、國家與活動日期。食譜等其他主題先使用共用列表與詳情欄位。
- 提供手動清單，以及保存搜尋文字與篩選條件的動態清單。
- AI 重跑保留人工修改，除非使用者明確重設欄位。地點確認結果不被重跑覆寫。
- AI 可提議新主題，整體檢查由使用者主動觸發；新增或合併須核准，合併前預覽收藏與動態清單，保留舊名稱作搜尋別名。
- 完整備份含資料庫與附件；支援還原、JSON 匯出。刪除須確認，清除該收藏搜尋資料及無引用附件，保留共用地點。

## 技術預設，隨本規格確認

- 單一 repository；Next.js App Router、TypeScript 前端，Python FastAPI 後端，SQLAlchemy 與 Alembic 管理 SQLite 資料與遷移。Next.js 透過 HTTP API 存取業務資料，不直接開資料庫。
- 本機啟動前端、API、獨立 Python worker、Ollama。預設僅綁定 loopback，以固定開發使用者運作；每筆私人資料保留 owner，未實作正式登入前不對外提供服務。
- SQLite WAL、本機持久化工作表、單一 worker 串行處理；工作具租約、嘗試次數與階段狀態。重啟可領回過期工作，最多自動嘗試三次，之後顯示失敗與手動重試；版本檢查阻止舊工作覆寫更新內容。
- 收藏先寫入，再擷取、分類與建立索引；狀態至少包含排隊、處理中、待補內文、完成、失敗；地點待確認另行表示，不阻塞一般收藏。
- Ollama qwen3:4b 做文字分類與擷取；驗證結構化輸出，不將模型結果當可信指令。multilingual-e5-small 以 CPU 產生向量，長文分段，保存模型與索引版本。
- SQLite FTS5 trigram 搭配一至二字元的參數化子字串搜尋；向量存 SQLite，以 Python 對 owner 與條件篩選後的候選計算餘弦相似度；混合模式以 RRF 合併文字與語意排名。無 embedding 時保留文字搜尋並標示狀態。
- 地圖以 Leaflet 與 OSM 標準圖磚起步，保留來源標示與可替換設定，不做離線預抓。Nominatim 僅供本地人工觸發的低量查詢，伺服器全域至多每秒一次、快取且不做輸入即查或 AI 自動批次查詢；明示查詢會送往外部服務。查無結果可手動選點。上線前重新檢查政策與台日韓覆蓋率，不保證免費公共服務可作正式服務依賴。
- 擷取器依平台分離，使用合法公開存取方式；不繞過登入或限制。HTTP 擷取具時間、回應大小、重新導向與 URL 安全限制，封鎖私有及本機位址並驗證重新導向。
- 本機檔案透過 Storage 介面存取，SQLite 保存檔案鍵而非硬編碼絕對路徑；MVP 僅做 LocalStorage，S3 adapter 延後。
- 備份時暫停寫入並等待 worker 安全停點，使用 SQLite backup API 取得一致資料庫及附件清單；還原在維護狀態驗證格式版本與完整性後執行，先保存還原前備份。

## 主要資料與介面

- 資料包含使用者、收藏、來源文字、主題與別名、標籤、欄位來源及人工修正、地點與候選、活動、收藏地點關聯、清單、工作、向量片段、主題提議與附件。
- FastAPI 提供 /api/v1 下的收藏新增／讀取／修改／刪除、重試、搜尋、清單、地點查詢／確認、活動修改、主題建議／預覽／核准、備份／還原與匯出端點，並產生 OpenAPI。
- 以穩定 ID 儲存清單條件與主題關係；合併主題預覽具版本檢查，使用交易更新關係與清單，不對被覆蓋的舊預覽直接套用。

## 驗收與交付順序

1. 完成網站、收藏 CRUD、補內文、去重與持久化背景工作，先用測試內容驗證完整流程。
2. 串接本地模型、分類、欄位修正、文字及語意搜尋、手動與動態清單。
3. 完成地點候選、人工確認與選點、地圖、多場活動、主題提議與合併。
4. 完成備份還原、刪除、錯誤重試、操作文件與公開示範資料，再以真實資料驗收。

- 真實集為使用者自願提供的 60 筆收藏，每平台 20 筆，覆蓋繁中、日文及台日韓地點；私人資料不提交公開版本庫。
- 主要分類正確率至少 80%；20 個預先定義的搜尋問題至少 16 個於前五筆命中。人工評分規則與預期答案須在調整模型前固定。
- 自動化測試覆蓋平台 ID 去重、人工修正保留、工作中斷恢復、地點多對多、活動不完整日期、主題合併與清單更新、短詞搜尋、擷取 URL 邊界、刪除引用、備份還原及路徑安全。
- 端到端驗證三平台讀取成功與失敗補內文、候選地點與手動選點、手機寬度操作及模型離線時文字搜尋。
- 記錄 RTX 3060 12GB 的分類耗時、失敗率、顯存與搜尋延遲，實測後公布數據，不預先承諾未量測的速度。
- 本地 MVP 通過後，另設正式登入、跨使用者權限驗證、HTTPS、配額、雲端儲存、監控與自動備份的上線關卡。
